# My Portfolio (Next.js + TypeScript)

## Run it
1. `npm install`
2. `npm run dev` → open http://localhost:3000

## Make it yours
Open `app/data.ts` and change: name, email, role, intro, about text.
Projects load automatically from your GitHub (`profile.github`).
Want a nicer title/description for a repo? Add it to `featured` in the same file.

## Put it online (free)
Push to GitHub → go to vercel.com → "Add New Project" → pick the repo → Deploy.
